# 위험 신호 판단 기준

문진 중 사용자의 말·글에서 위험 신호를 찾으면 바로 EMERGENCY(E01 응급 전환)로 보내요. 이 문서는 그 규칙(`src/main/resources/data.sql`의 red_flag_rule·red_flag_keyword)이 어떤 공식 기준에 근거하는지 정리해요.

**기준:** 보건복지부 고시 「한국 병원 전 응급환자 중증도 분류기준」(Pre-KTAS, 119 구급대가 쓰는 공식 분류)의 **2등급 이상(중증응급)**이면 응급으로 보내요. 앱은 혈압·산소포화도를 잴 수 없어서, 가슴 통증과 갑자기 생긴 한쪽 저림은 보수적으로 응급으로 둬요.

## 규칙과 근거

`data.sql` 규칙 12개, 키워드 286개예요. 같은 group은 OR, 다른 group끼리는 AND이고, 입력의 띄어쓰기를 지우고 비교해요. 키워드 바로 앞의 "안", 바로 뒤의 "~지 않"·"~은 없"은 부정으로 보고 그 키워드는 없는 것으로 판정해요.

- 강원 사투리와 노인 구어 표현도 넣었어요. 예: 가심이 아퍼유, 숨이 맥혀요, 까무러쳤어요, 골이 빠개질 것 같아요, 왼짝 팔, 피를 게웠어요
- 어간이 바뀌는 활용형과 과거형은 따로 넣어요. 예: 넘어가/넘어갈, 파랗/파래, 심하/심해, 아프/아팠, 쓰러지셨
- "대답이 없어요"처럼 "없다"는 말 자체가 증상이면, 키워드에 "없"까지 넣어야 부정으로 처리되지 않아요 (예: `대답이없`, `반응이없`).

| # | 규칙 → 응답 `redFlagCategory` | 걸리는 말 (예) | 근거 |
| --- | --- | --- | --- |
| 1 | 흉통 → `CHEST_PAIN` | 가슴·심장 + 조여요·쥐어짜요·답답해요·아파요·불편해요·묵직해요 | Pre-KTAS 흉통(심장성) "심장성 통증" 2등급. 앱은 심장성인지 알 수 없어 가슴 통증·불편감은 항상 응급 (예외). 질병관리청: 노인은 증상이 약하게 나타날 수 있음 |
| 2 | 뇌졸중 의심 (말·얼굴) → `STROKE` | 말이 어눌해요, 입이 한쪽으로 돌아갔어요, 마비 | Pre-KTAS 사지약화/뇌졸중 증상 "발병 24시간 이내" 2등급, 질병관리청 언어 장애·편측 마비 |
| 3 | 의식 저하 → `CONSCIOUSNESS` | 의식을 잃었어요, 기절했어요, 깨워도 반응이 없어요 | Pre-KTAS 의식수준의 변화 1~2등급, 실신/전실신 "전구증상 없음" 2등급 |
| 4 | 호흡곤란 → `BREATHING` | 숨이 막혀요, 숨쉬기 힘들어요, 숨을 못 쉬어요, 입술이 파래요 | Pre-KTAS 숨참 "중등도 호흡곤란" 2등급, 시행규칙 "급성호흡곤란" |
| 5 | 심한 출혈 → `BLEEDING` | 피가 계속 나요, 코피가 안 멈춰요 | Pre-KTAS 코피 "적절한 압박에도 멈추지 않는 코피" 2등급, 시행규칙 "지혈이 안되는 출혈" |
| 6 | 뇌졸중 의심 (한쪽 힘 빠짐) → `STROKE` | 한쪽·왼팔·오른다리 + 힘이 빠져요·안 움직여요 | Pre-KTAS 사지약화/뇌졸중 증상 24시간 이내 2등급, 질병관리청 편측 마비 |
| 7 | 피를 토함 → `BLEEDING` | 피를 토했어요, 각혈 | Pre-KTAS 토혈 "활동성 토혈" 2등급, 시행규칙 "계속되는 각혈"·"급성 위장관 출혈" |
| 8 | 숨참 (갑자기·쉬어도) → `BREATHING` | 갑자기·가만히 있어도·쉬어도 + 숨이 차요 | Pre-KTAS 숨참: 중등도 2등급, 경증 3등급. "계단 오를 때 숨이 차요"는 응급 아님 |
| 9 | 뇌졸중 의심 (갑자기 한쪽 저림) → `STROKE` | 갑자기 + 한쪽·왼팔 + 저려요 | Pre-KTAS 감각상실 "새로 발병" 3등급이지만 질병관리청 "갑자기 한쪽이 무감각해지면 119" 기준으로 응급 (예외) |
| 10 | 뇌졸중 의심 (갑작스러운 시력 변화) → `STROKE` | 갑자기 + 앞이 안 보여요 | Pre-KTAS 시력장애 "급성/갑작스런 시력변화" 2등급, 시행규칙 "급성 시력 손실", 질병관리청 시각 장애 |
| 11 | 뇌졸중 의심 (가장 심한 두통) → `STROKE` | 머리 + 깨질 것 같아요·이렇게 아픈 건 처음 | Pre-KTAS 두통 "지금까지 경험했던 두통 중 가장 심함" 2등급, 질병관리청 극심한 두통 |
| 12 | 많은 양의 흑색변·혈변 → `BLEEDING` | 검은 변·혈변 + 많이·계속 | Pre-KTAS 혈변/흑색변 "많은양의 흑색변 또는 직장출혈" 2등급, 시행규칙 "급성 위장관 출혈" |

`redFlagCategory`는 노션 API 명세의 5개 값(CHEST_PAIN, BREATHING, STROKE, CONSCIOUSNESS, BLEEDING)만 써요. 시력 변화와 가장 심한 두통은 질병관리청이 뇌졸중 조기 증상으로 안내해서 `STROKE`로 보내요.

## 입력과 판정 결과

전체 테스트 문장은 [`src/test/resources/red-flag-cases.csv`](../../src/test/resources/red-flag-cases.csv)에 있어요 (80개, 문장·기대 결과·이유). `RedFlagDetectorCasesTest`가 `./gradlew build`와 CI에서 매번 이 목록으로 판정해서, 규칙을 고치다 기존 판정이 깨지면 빌드가 실패해요. 아래는 그중 일부예요.

| 입력 | 판정 | 이유 |
| --- | --- | --- |
| 가슴이 조금 아파요 | `CHEST_PAIN` | 가슴 통증은 항상 응급 |
| 가슴 통증이 심하지 않아요 | `CHEST_PAIN` | 통증은 있다는 뜻 (부정은 "심하다"에 걸림) |
| 가슴이 좀 불편하고 기운이 없어요 | `CHEST_PAIN` | 가슴 불편감 (노인은 약하게 나타남) |
| 가슴은 안 아파요 | 응급 아님 | 부정 |
| 숨쉬기가 힘들어요 | `BREATHING` | 중등도 이상 호흡곤란 |
| 갑자기 숨이 차요 / 가만히 있어도 숨이 차요 | `BREATHING` | 급성·안정 시 호흡곤란 |
| 계단 오를 때 숨이 차요 | 응급 아님 | 경증 (3등급) |
| 한쪽 팔에 힘이 빠져요 | `STROKE` | 편측 마비 |
| 한쪽 다리가 아파요 | 응급 아님 | 통증만으로는 뇌졸중 증상이 아님 |
| 갑자기 왼팔이 저려요 | `STROKE` | 갑작스러운 편측 감각 이상 (예외) |
| 오른쪽 다리가 저려요 | 응급 아님 | "갑자기"가 없음 |
| 갑자기 앞이 안 보여요 | `STROKE` | 갑작스러운 시력 변화 |
| 눈이 침침하고 잘 안 보여요 | 응급 아님 | 만성·점진적 (4등급) |
| 머리가 깨질 것 같아요 | `STROKE` | 가장 심한 두통 |
| 머리가 아프고 어지러워요 | 응급 아님 | 두통·어지럼만으로는 3등급 이하 |
| 코피가 안 멈춰요 | `BLEEDING` | 압박에도 멈추지 않는 코피 |
| 코피가 났는데 멈췄어요 | 응급 아님 | 멈춘 코피 (3등급) |
| 검은 변을 많이 봤어요 | `BLEEDING` | 많은 양의 흑색변 |
| 어제 기절했어요 | `CONSCIOUSNESS` | 의식 소실 (지금 상태를 알 수 없어 응급) |

**알려진 한계**

- 문장을 나누지 않아요. "가슴은 안 아파요, 무릎이 아파요"는 응급으로 잡혀요 (뒤의 "아파요"가 걸림).
- 법령 응급증상 중 자살·자해, 약물·농약 중독, 얼굴이 붓는 알레르기, 머리 부상은 응급 종류가 따로 없어 잡지 않아요 (2026-11-04 팀 결정).
- 이 기준은 공식 자료를 앱 규칙에 맞춘 것이고 의료진 검토를 대신하지 않아요. 화면에는 "진단이 아닌 안내" 문구를 유지해요.

## 규칙을 고칠 때

1. 근거가 되는 등급(고시 별표의 판단기준과 코드)을 먼저 찾아요. `sources/prektas-adult-excerpt.md`에 관련 증상이 모여 있어요.
2. `data.sql`의 규칙 주석과 이 문서의 "규칙과 근거" 표를 같이 고쳐요.
3. `src/test/resources/red-flag-cases.csv`에 응급이어야 하는 말과 아니어야 하는 말을 함께 추가하고 `./gradlew test --tests '*RedFlagDetectorCasesTest'`로 확인해요.
4. 키워드는 띄어쓰기 없이, 활용형(과거형·어간 변화)까지 넣어요. 새 키워드가 다른 증상 문장에서 잘못 걸리지 않는지 "응급 아님" 문장도 같이 넣어요.
