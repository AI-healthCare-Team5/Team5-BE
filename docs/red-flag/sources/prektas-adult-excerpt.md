# Pre-KTAS 성인 기준표 발췌

보건복지부 고시 「한국 병원 전 응급환자 중증도 분류기준」 [별표 1] 중증도 분류 성인(현행: 제2025-230호, 2025-12-29 시행)에서 진료한장 위험 신호 규칙이 쓰는 증상 소분류만 뽑았어요. 원본은 같은 폴더의 `prektas-annex1-adult-2025-230.pdf`예요.

- 분류 코드 5자리: 연령(C=성인) · 대분류 · 소분류 · 판단기준 구분 · 판단기준
- 등급: 1~2 중증응급, 3 중증응급의심, 4~5 경증응급·비응급 (고시 제5조)
- 활력징후(호흡곤란 정도, 쇼크, GCS 등)로 정하는 공통 기준도 그대로 옮겼어요. 앱은 이 값을 잴 수 없어요.
